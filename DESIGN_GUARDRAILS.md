# DESIGN GUARDRAILS — PREMIUM SAAS

These rules apply to every new or modified UI component.

## Visual consistency
- Reuse existing design tokens and shared UI primitives.
- Do not introduce arbitrary colors, shadows, spacing values, or radii.
- Match the established application shell and page composition.
- Preserve a consistent typography hierarchy.

## Composition
- Design information hierarchy before styling components.
- Avoid repetitive card-based layouts without a functional reason.
- Respect content density and user workflows.
- Use spacing to establish clear relationships.

## Visual restraint
- No decorative gradients unless specifically justified.
- No unnecessary icons, badges, shadows, or colored backgrounds.
- No excessive glassmorphism.
- No arbitrary animation.
- Prefer subtle surface contrast over decorative depth.

## SaaS usability
- Tables must remain efficient and scannable.
- Forms must remain clear and compact.
- Dashboards must highlight meaningful information.
- Critical actions must remain discoverable.
- Loading, empty, error, and success states must be supported.

## Before completing any UI task
Verify:
1. Does this follow the design-dna?
2. Does it match the visual quality of existing polished screens?
3. Is it visually coherent with neighboring components?
4. Are spacing, typography, and alignment precise?
5. Does it avoid generic AI-generated UI patterns?
6. Does it preserve real product functionality?

If not, refine the implementation before considering the task complete.
